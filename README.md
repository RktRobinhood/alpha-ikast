# Alpha Ikast

Alpha Ikast is an exploratory school EdTech project inspired by Alpha School's orchestration model: combine curriculum, evidence of learning, mastery estimates, learning activities, and student/teacher dashboards into a coherent system.

The intended destination is not yet a finished product specification. The project starts with IB Mathematics as a proving ground while preserving a path to other IB subjects and their very different activity and evidence types.

## Current status

- Discovery and framing
- Prior research has been captured but not yet independently verified
- Web-hosted, cross-device delivery is the only implementation constraint selected so far
- Backend, AI runtime, and broader technology stack remain undecided
- GitHub Issues will hold the Wayfinder map and investigation tickets

## Working principle

AI may assist with tutoring, content operations, and analysis, but consequential mastery and progression decisions should be grounded in inspectable student evidence and an explicit model rather than an opaque language-model judgment.

The project starts from existing open-source systems and established educational methods, validates them in the AA SL context, and adapts only where the classroom reveals a genuine gap.
